# CinemaBot - Telegram Bot для поиска фильмов

## Описание
Асинхронный бот для поиска информации о фильмах и сериалах. Предоставляет постеры, рейтинги, описания и ссылки для просмотра. Сохраняет историю запросов и статистику в PostgreSQL.

## Команды
- `/start` - Приветствие
- `/help` - Справка по командам
- `/stats` - Статистика запросов (сколько раз каждый фильм предлагался)
- `/history` - История поисковых запросов

## Как использовать
Просто отправьте название фильма в чат, например:
- "Venom"
- "Остров собак"
- "Мстители: война бесконечности"

Бот автоматически найдет информацию о фильме и покажет:
🎬 Постер
⭐ Рейтинг
📝 Описание
🔗 Ссылки для просмотра

## Технологии
- **Python 3.13+** - основной язык
- **aiogram 3.10+** - Telegram Bot API
- **SQLAlchemy 2.0+** - ORM для PostgreSQL
- **asyncpg** - асинхронный драйвер БД
- **aiohttp** - асинхронные HTTP-запросы
- **BeautifulSoup4** - парсинг страниц

## Архитектура
1. **Основной модуль** - обработка команд и сообщений
2. **Модуль поиска** - парсинг информации с IMDB и Кинопоиска
3. **Модели БД** - хранение истории и статистики запросов
4. **Асинхронная обработка** - все операции неблокирующие

## База данных
Хранит:
- Историю поисковых запросов пользователей
- Статистику показов фильмов
